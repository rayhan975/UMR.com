# UMR.TZY — Roblox Tools Hub

Website statis premium neon yang bisa dibuka dari HP Android.

## Fitur yang sudah bekerja
- Desain responsif untuk HP dan desktop.
- Audio preview lokal di browser (file tidak diupload ke server).
- Notebook ID audio dan decal, disimpan di localStorage browser.
- Sky preset visual dengan catatan dan tombol salin.
- Checklist Roblox Studio dan tautan resmi Creator Hub.
- Pencarian ID dasar melalui validasi format angka.

## Batasan penting
- Audio Preview **bukan** upload audio ke Roblox.
- Website statis ini tidak bisa mem-bypass moderasi, permission, atau pembatasan audio Roblox.
- ID yang disimpan di localStorage hanya tersimpan di browser/perangkat yang sama; bukan database online.
- Tidak ada login, pembayaran, backend, atau dashboard admin.
- Gunakan audio/decal yang kamu punya hak dan izin untuk gunakan.

## Cara menjalankan dari HP
1. Ekstrak ZIP.
2. Buat repository baru di GitHub, misalnya `umr-tzy-tools`.
3. Upload `index.html`, `style.css`, `app.js`, dan `README.md` ke root repository.
4. Buka Settings → Pages.
5. Pada Build and deployment, pilih `Deploy from a branch`.
6. Pilih branch `main` dan folder `/(root)`, lalu Save.
7. Tunggu proses publish selesai. GitHub menampilkan alamat Pages di bagian Pages.

Catatan: sebelum menggunakan GitHub Pages untuk situs publik, periksa ketentuan GitHub Pages terbaru. Untuk layanan yang akan dipakai sebagai bagian dari bisnis/transaksi komersial, pilih host yang ketentuannya secara eksplisit mengizinkan penggunaan itu.
